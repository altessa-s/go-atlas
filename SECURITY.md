# Security Policy

## Reporting a Vulnerability

The go-atlas team takes security seriously. We appreciate your efforts to responsibly disclose your findings.

**Please do NOT report security vulnerabilities through public GitHub issues.**

Instead, please report them via email to:

**security@altessa-s.com**

Include the following information in your report:

- Description of the vulnerability
- Steps to reproduce or proof of concept
- Affected versions
- Any potential impact assessment

## Response Timeline

| Action                      | Timeline               |
|-----------------------------|------------------------|
| Acknowledgment of report    | Within 48 hours        |
| Initial assessment          | Within 5 business days |
| Fix development and release | Based on severity      |

## Supported Versions

| Version        | Supported           |
|----------------|---------------------|
| Latest release | Yes                 |
| Previous minor | Security fixes only |

## Disclosure Policy

- We will work with you to understand and address the issue.
- We will acknowledge your contribution in the release notes (unless you prefer to remain anonymous).
- We ask that you give us a reasonable amount of time to address the issue before public disclosure.

## Scope

This policy applies to the `github.com/altessa-s/go-atlas` Go module and all its sub-packages.
