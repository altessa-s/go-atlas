# proto

Protocol Buffers utilities for the Atlas framework domain layer. Provides field mask operations for filtering, pruning, and applying
update masks on protobuf messages with support for well-known types and `google.api.field_behavior` annotations.

## Subpackages

| Package                    | Description                                                                            |
|----------------------------|----------------------------------------------------------------------------------------|
| [fieldmask](./fieldmask)   | Hierarchical field mask with filter, prune, union, intersection, and update operations |
