# goconfig

```go
import "github.com/altessa-s/go-atlas/cmd/goconfig"
```

Configuration file converter for go-tools config parser.

## Overview

`goconfig` converts between different configuration formats, understanding the go-tools config parser structure with proper field name transformations and nesting.

## Installation

```bash
go install github.com/altessa-s/go-atlas/cmd/goconfig@latest
```

## Usage

### Convert YAML to Environment Variables

```bash
goconfig convert --from config.yaml --to .env
```

### Convert Environment Variables to YAML

```bash
goconfig convert --from .env --to config.yaml
```

### Convert TOML to Environment Variables

```bash
goconfig convert --from config.toml --to .env
```

## Supported Formats

| Format | Extensions | Description |
|--------|------------|-------------|
| YAML | `.yaml`, `.yml` | YAML configuration files |
| TOML | `.toml` | TOML configuration files |
| Env | `.env` | Environment variable files |
| Markdown | `.md` | Documentation tables |

## Conversion Rules

### Field Name Transformation

- camelCase → SCREAMING_SNAKE_CASE
- Nested structures use `__` (double underscore) delimiter
- Array indices are numbered: `ARRAY__0`, `ARRAY__1`

### Examples

| YAML Structure | Environment Variable |
|----------------|---------------------|
| `grpc.interceptors.realIp.enabled` | `GRPC__INTERCEPTORS__REAL_IP__ENABLED` |
| `database.connectionPool.maxSize` | `DATABASE__CONNECTION_POOL__MAX_SIZE` |
| `logging.handlers[0].level` | `LOGGING__HANDLERS__0__LEVEL` |

## Commands

### convert

Convert configuration between formats:

```bash
goconfig convert [flags]

Flags:
      --from string         Source file or directory
      --to string          Destination file
      --from-format string Format of source (auto-detect by extension)
      --to-format string   Format of destination (auto-detect by extension)
      --parse-comments     Include commented lines in conversion
```

## Configuration Examples

### YAML to .env

Input (`config.yaml`):
```yaml
database:
  host: localhost
  port: 5432
  pool:
    maxSize: 10
    timeout: 30s

logging:
  level: info
  handlers:
    - type: console
      format: json
    - type: file
      path: /var/log/app.log
```

Output (`.env`):
```bash
DATABASE__HOST=localhost
DATABASE__PORT=5432
DATABASE__POOL__MAX_SIZE=10
DATABASE__POOL__TIMEOUT=30s
LOGGING__LEVEL=info
LOGGING__HANDLERS__0__TYPE=console
LOGGING__HANDLERS__0__FORMAT=json
LOGGING__HANDLERS__1__TYPE=file
LOGGING__HANDLERS__1__PATH=/var/log/app.log
```

### .env to YAML

Input (`.env`):
```bash
SERVER__HOST=0.0.0.0
SERVER__PORT=8080
SERVER__TLS__ENABLED=true
SERVER__TLS__CERT_FILE=/etc/ssl/cert.pem
SERVER__TLS__KEY_FILE=/etc/ssl/key.pem
```

Output (`config.yaml`):
```yaml
server:
  host: 0.0.0.0
  port: 8080
  tls:
    enabled: true
    certFile: /etc/ssl/cert.pem
    keyFile: /etc/ssl/key.pem
```

## Directory Processing

Convert all configuration files in a directory:

```bash
# Merge all configs in ./configs/ into single .env
goconfig convert --from ./configs/ --to merged.env

# Convert each file individually
for f in configs/*.yaml; do
  goconfig convert --from "$f" --to "env/$(basename "$f" .yaml).env"
done
```

## Integration with go-tools

This converter produces environment variables compatible with go-tools config parser:

```go
// Load environment variables generated by goconfig
cfg, err := config.Load[MyConfig]()
```

## Format Detection

File format is automatically detected by extension:

- `.yaml`, `.yml` → YAML
- `.toml` → TOML  
- `.env` → Environment variables
- `.md` → Markdown tables

Override with `--from-format` and `--to-format` flags.
