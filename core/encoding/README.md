# encoding

Encoding, hashing, and serialization utilities. Each subpackage can be imported independently.

## Subpackages

| Package                        | Description                                              |
|--------------------------------|----------------------------------------------------------|
| [hash](./hash)                 | Deterministic, hex-encoded SHA-256 digests               |
| [serializer](./serializer)     | Format-agnostic `Serializer` interface with JSON default |
